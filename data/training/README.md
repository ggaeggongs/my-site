# 공시 AI 도우미 · 학습(지식) 데이터 폴더

이 폴더는 **AI 챗봇이 사실 근거로 사용할 자료**를 모아두는 곳입니다.
여기에 파일을 넣어두면, Claude가 내용을 읽어 **제목·분류·내용**으로 정리한 뒤
Supabase의 `disclosures` 테이블(DB)에 저장합니다. 저장된 자료가 많을수록 챗봇이 더 정확해집니다.

## 넣는 방법
- 이 폴더(`data/training/`)에 **`.md` 또는 `.txt`** 파일로 자유롭게 넣어주세요.
- 형식은 신경 쓰지 않으셔도 됩니다. 회사 소개, 공시 요약, 사업 설명, FAQ 등 **사실 위주**의 글이면 됩니다.
- 파일을 넣은 뒤 저(Claude)에게 "학습 데이터 반영해줘"라고 말씀해 주세요.
  → 제가 파일을 읽고, 제목/분류/내용으로 구조화해서 Supabase DB에 저장(중복은 갱신)합니다.

## 권장(선택) 형식
꼭 지키지 않아도 되지만, 아래처럼 적어주시면 더 정확히 분류됩니다.

```
# 제목: 푸른저축은행 2025 상반기 요약
# 분류: 재무
# 출처: https://dart.fss.or.kr
# 기준일: 2025-06-30

본문 내용을 자유롭게 적습니다. 사실과 수치 위주로.
```

## 주의
- **사실·공개 가능한 정보만** 넣어주세요. (개인정보·미공개 내부자료 금지)
- 이 폴더의 파일은 '원본'이고, 챗봇이 실제로 참고하는 것은 여기서 옮겨 저장한 **Supabase DB**입니다.
